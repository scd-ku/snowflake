Model & Help

このアプリでできること

  • 温度と過飽和度を変え、板状・柱状 / 針状・扇六花・樹枝状の成長を比較できます。
  • 「成長スピード」スライダーで、計算・描画の進行速度を0.25×〜4×の範囲で変更できます。
  • 「プログラムを使用」をONにすると、結晶が成長する途中で温度・過飽和度を順番に切り替えられます。
  • 「水蒸気（背景）を表示」で、結晶周囲の無次元過飽和度 σ の分布を確認できます。
  • 柱状モードでは c 軸方向の成長量を別状態として計算し、2D格子に奥行きを加えた擬似3D表示を行います。

基本式

六角格子の非氷セルでは、水蒸気の過飽和度 σ を近傍6セルとの離散拡散で更新します。

σᵢ(t+1) = σᵢ(t) + D [ (1/6) Σⱼ∈N(i) σⱼ(t) − σᵢ(t) ]

氷に接する境界セルでは、局所付着係数 αᵢ に比例して氷質量 m を蓄積します。

mᵢ(t+1) = mᵢ(t) + κ αᵢ σᵢ(t) mᵢ ≥ m_c ⇒ freeze(i)

付着係数は、温度依存の面成長速度、六回対称異方性、局所形状から決めます。

αᵢ = α_prism(T) · A₆(θᵢ) · A_shape(nᵢ,rᵢ,σᵢ) A₆(θ) = 1 + ε · max[0, cos(6θ)]²

c 軸方向の厚さ h は、基底面の付着係数 α_basal を使って別に更新します。

h(t+1) = h(t) + κ_h α_basal(T) σ∞

温度と形態

この版では、−5 ℃付近で基底面成長を相対的に速くして柱状 / 針状、−15 ℃付近で柱面成長を相対的に速くして板状系を作ります。−15 ℃付近で過飽和度を高くすると、拡散律速の先端不安定性を強めて樹枝状へ移行します。中程度の過飽和度では、主枝と面成長を両立させて扇六花を作ります。

今回のアルゴリズム変更

  • 「重み付き抽選だけで枝を作る」方式をやめ、拡散場 → 境界への堆積 → 閾値氷化という順で更新します。
  • 平滑な板では隣接氷セル数が多い面を優先し、樹枝状では先端と六主軸を優先します。
  • 樹枝状では Mullins–Sekerka 型の拡散不安定性を教育用に近似し、主枝から一定間隔で側枝が生じやすい項を加えています。
  • 六回対称ロックONでは、氷化したセルを60°回転した5点へ同時反映します。

モデルの範囲

実際の雪結晶は三次元で、基底面・柱面の分子付着、表面前融解、気圧、熱輸送、結晶欠陥などにも依存します。このアプリは、代表形態とその原因を比較して学ぶための教育用メソスケールモデルです。
